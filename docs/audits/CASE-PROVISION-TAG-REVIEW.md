# Case/provision tag review

## Summary

Reviewed 62 disappeared full-decision `(provision, case page)` pairs, excluding the withdrawn `2010-15` stub. The old index records these pairs only as `cases.jsonl:bco_cited_as` and/or `bco_cited_current`; that establishes their origin as metadata, not their correctness. The table classifies source text separately from the legacy metadata. `Yes` under observation means preserve a corrected citation observation. A text hit may be a decision citation, a quoted lower-court or party position, or a contextual mention; the cited voice is flagged for review. Canonical inclusion is supported when the majority or a substantive concurrence analyzes or applies the provision; a dissent, party/lower-court statement, factual record, or historical footnote alone does not qualify.

Of the 62 pairs, 28 have a traceable case-level citation or mention; 34 lack support or are misattributed. The review supports 22 canonical `bco_provisions` tags in the majority or a substantive concurrence. Six text observations should not become canonical tags because they occur only in a dissent, lower-court rationale, factual record, or historical footnote; one apparent observation was actually from the adjacent 2023-13 docket. These recommendations include 2024-16 / BCO 12-5.e and its two express standards of review (39-3.3 and 39-3.4). For the 15 newer cases without a current `judicial_cases.jsonl` row, these tags are promotion candidates only after a canonical case record is added. The strongest negative finding is the five lost `1995-04` tags: the reconciled candidate is misattached from the 2005-11 mention and the canonical row is marked `ignore_extracted`; the 1995-04 page supports BCO 20-2, not these lost tags. The two 1990 docket identities are judged by case page/case_id, not the erroneous `canonical_number` values. Fifteen newer cases have no current `judicial_cases.jsonl` row, so positive page evidence is an input candidate, not a canonical record insertion recommendation by itself.

## Method and limits

- Compared `HEAD:index/case_provision_index.json` with the current generated index using unique `(provision, url)` keys; excluded the withdrawn stub.
- Read the full case page for each pair and searched the page for provision-number references; table evidence gives exact one-based case-page line numbers when a match exists. “No matching provision citation” means no matching text was found on that page, not that no underlying record could ever contain it.
- Each page identifies its Minutes volume and printed-page span. Where matching BCO text was traceable within that span, the table includes the exact Minutes Markdown line numbers; otherwise it gives only the case-page result.
- Primary source for these 2023–2025 decisions is the [official 52nd General Assembly Minutes, Appendix Q](https://www.pcahistory.org/pca/ga/52nd_pcaga_2025.pdf), with printed page references noted in the table where relevant. The repository Markdown is a searchable transcription of that source.
- Recommendations separate preservation as `bco_cited_as` observation from inclusion in canonical `bco_provisions`. Substantive concurrences qualify when they analyze or apply a provision; dissent-only, party, lower-court, factual-record, and historical mentions do not.
- For malformed legacy labels, preserve only after normalization to what the decision actually cites; do not carry malformed strings literally.
